## TL;DR (Core Vector)
Искусственный интеллект (ИИ) — свойство автоматических систем принимать решения и выполнять задачи, ранее считавшиеся прерогативой человека. Включает машинное обучение, обработку естественного языка, компьютерное зрение и экспертные системы.

## Определение (Definition)
Искусственный интеллект — раздел информатики, занимающийся созданием систем, способных выполнять задачи, требующие человеческой когнитивной функции: обучение, рассуждение, восприятие, понимание языка и принятие решений.

## Ключевые факты (Facts)
- Термин введён в 1956 году на конференции в Дартмуте (Джон Маккарти)
- Тест Тьюринга (1950) — классический критерий «разумности» машины
- Три волны ИИ: символический (1950-80-е), статистический/ML (1990-2010-е), нейросетевой/deep learning (2012-н.в.)
- Большие языковые модели (LLM): GPT-4, Claude, Qwen — >100 млрд параметров
- Генеративный ИИ создаёт новый контент (текст, изображения, код)
- AGI (сильный ИИ) — гипотетическая система, превосходящая человека во всех задачах — не достигнут

## Ядро для ИИ (Embedding Target)
Современный ИИ базируется на трёх столпах: данные, алгоритмы, вычислительные мощности. Deep learning использует многослойные нейронные сети для извлечения иерархических признаков из данных.

Подходы:
- Supervised learning — обучение с учителем (классификация, регрессия)
- Unsupervised learning — без учителя (кластеризация, снижение размерности)
- Reinforcement learning — обучение с подкреплением (агент + среда + reward)
- Transfer learning — перенос знаний с предобученной модели

Трансформеры (2017) — архитектура на основе механизма внимания (self-attention), ставшая стандартом для NLP и мультимодальных задач.

## Применение / Практическое использование
- NLP: машинный перевод, суммаризация, чат-боты, генерация кода
- Компьютерное зрение: распознавание лиц, медицинская диагностика, автономные автомобили
- Рекомендательные системы: Netflix, YouTube, Amazon
- Робототехника: управление манипуляторами, навигация
- ИИ-агенты: Cursor, Copilot, автопилот

## Противоречия/Нюансы (Caveats)
- ИИ не «понимает» в человеческом смысле — это статистическая аппроксимация
- Галлюцинации LLM: генерация правдоподобного, но ложного контента
- Bias в данных → bias в предсказаниях (этическая проблема)
- ИИ не обладает сознанием, намерениями или эмоциями — это математические модели
