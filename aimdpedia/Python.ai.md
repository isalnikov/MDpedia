## TL;DR (Core Vector)
Python — высокоуровневый язык программирования общего назначения с динамической типизацией, автоматическим управлением памятью и поддержкой множественных парадигм (ООП, функциональное, процедурное).

## Определение (Definition)
Python — интерпретируемый язык программирования с динамической семантикой, встроенными структурами данных высокой уровня и динамическим связыванием. Поддерживает модульную и объектно-ориентированную разработку.

## Ключевые факты (Facts)
- Создан Гвидо ван Россумом, первая публикация — 1991 год
- Динамическая типизация + garbage collection (reference counting + cyclic GC)
- Интерпретируется байт-кодом CPython (.pyc), не компилируется в машинный код
- GIL (Global Interpreter Lock) ограничивает истинную многопоточность в CPython
- Индекс TIOBE 2024: #1 среди языков программирования
- Стандартная библиотека: 200+ модулей (os, sys, collections, itertools и др.)
- Пакетный менеджер: pip, репозиторий: PyPI (>450,000 пакетов)

## Ядро для ИИ (Embedding Target)
Python использует философию «явного лучше неявного» (Zen of Python, PEP 20). Ключевые принципы: читаемость кода, минимализм синтаксиса, отступы как часть синтаксиса.

Управление памятью: подсчёт ссылок + циклический сборщик мусора (gc module). Все объекты в Python — экземпляры классов, включая встроенные типы (int, str, list).

Интерпретация: исходный код → байт-код (.pyc) → выполнение в виртуальной машине CPython. Альтернативные реализации: PyPy (JIT-компиляция, в 3-5x быстрее), Jython (JVM), IronPython (.NET).

Типичные области: веб-разработка (Django, FastAPI), data science (pandas, numpy), ML (PyTorch, TensorFlow), автоматизация, скриптинг.

## Применение / Практическое использование
- Веб-разработка: Django, Flask, FastAPI
- Data Science: pandas, numpy, scipy, matplotlib
- Machine Learning: PyTorch, TensorFlow, scikit-learn
- Автоматизация и DevOps: Ansible, Fabric
- Научные вычисления: Jupyter, SymPy

## Противоречия/Нюансы (Caveats)
- Python медленнее C/C++/Rust в 10-100x для вычислительных задач (компенсируется numpy/C-расширениями)
- GIL не позволяет использовать несколько ядер в многопоточности (используйте multiprocessing или asyncio)
- Python 2 vs Python 3: Python 2 завершён (EOL 2020), но legacy-код ещё встречается
- Mutable default arguments: `def f(x=[])` — один объект на все вызовы
