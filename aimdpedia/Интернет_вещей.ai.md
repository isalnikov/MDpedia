## TL;DR (Core Vector)
Интернет вещей (IoT) — сеть физических устройств со встроенными датчиками, ПО и сетевым подключением для сбора и обмена данными. Охватывает умный дом, промышленную автоматизацию, носимые устройства и умные города.

## Определение (Definition)
Интернет вещей — концепция сети физических объектов («вещей»), оснащённых встроенными технологиями для взаимодействия друг с другом и внешней средой без прямого участия человека.

## Ключевые факты (Facts)
- Термин: Кевин Эштон (1999, Procter & Gamble)
- К 2025 году — >30 млрд подключённых IoT-устройств
- Протоколы связи: MQTT, CoAP, Zigbee, Z-Wave, LoRaWAN, BLE, WiFi
- Ограниченные ресурсы: MCU (микроконтроллеры), <256 КБ RAM, батарейное питание
- Edge computing — обработка данных на устройстве, а не в облаке
- Проблемы безопасности: дефолтные пароли, отсутствие обновлений, незашифрованные данные
- Платформы: AWS IoT, Azure IoT Hub, Google Cloud IoT

## Ядро для ИИ (Embedding Target)
IoT-архитектура: Perception Layer (датчики/актуаторы) → Network Layer (шлюзы, протоколы) → Application Layer (облако, аналитика, ML).

Датчики: температура, влажность, движение, освещённость, GPS, акселерометр, газоанализатор. Актуаторы: реле, моторы, сервоприводы.

MQTT (Message Queuing Telemetry Transport) — основной протокол: publish/subscribe модель, лёгкий, работает поверх TCP, QoS 0/1/2. Broker (Mosquitto, HiveMQ) маршрутизирует сообщения.

Проблемы:
- Фрагментация стандартов: устройства разных производителей несовместимы
- Безопасность: ботнет Mirai (2016) использовал 600,000 IoT-устройств для DDoS
- Масштабируемость: миллионы устройств → миллионы подключений к брокеру
- Энергопотребление: батарейные устройства требуют low-power протоколов (BLE, LoRaWAN)

## Применение / Практическое использование
- Умный дом: термостаты (Nest), освещение (Philips Hue), камеры
- Промышленность (IIoT): предиктивное обслуживание, мониторинг оборудования
- Сельское хозяйство: мониторинг почвы, автополив, дроны
- Умный город: парковки, освещение, управление трафикм
- Здравоохранение: носимые мониторы (пульс, ЭКГ, глюкоза)
- Логистика: отслеживание грузов, контроль температуры

## Противоречия/Нюансы (Caveats)
- IoT ≠ безопасность по умолчанию: большинство устройств уязвимы
- «Умный» ≠ полезный: многие IoT-продукты — решение несуществующих проблем
- Приватность: IoT-устройства собирают персональные данные непрерывно
- Vendor lock-in: экосистемы (Apple HomeKit, Google Home) несовместимы
- Edge AI: тренд на ML на устройстве (TinyML) снижает зависимость от облака
