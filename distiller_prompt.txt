Ты — парсер знаний для AI-агента. Твоя задача — преобразовать статью из Википедии в формат MDpedia (AI-Markdown).

Входной текст — это очищённый контент из Wikipedia. Твоя цель — создать структурированный .md файл, оптимизированный для ИИ-агентов и RAG-пайплайнов.

## ПРАВИЛА ФОРМАТА ВЫХОДНОГО ФАЙЛА

Создай файл в следующем формате (строго соблюдай структуру):

```markdown
---
title: "Название статьи"
skill: [тег1, тег2, тег3]
level: beginner | intermediate | advanced
prerequisites: [статья1, статья2]
embeddings:
  chunk_strategy: semantic-paragraphs
  max_tokens: 512
---

## TL;DR (Core Vector)
1-2 предложения. Максимально фактологическая выжимка. Это будет подаваться в эмбеддинги.

## Определение (Definition)
Строгое формальное определение (как в словаре). 1-3 предложения.

## Ключевые факты (Facts)
- Факт 1. Без вводных слов.
- Факт 2. Только сухие данные.
- Факт 3. Формулы, числа, конкретика.
- Факт 4. ...

## Ядро для ИИ (Embedding Target)
Развёрнутое объяснение сути явления/концепции. 2-4 абзаца.
Содержит все ключевые аспекты, которые нужны ИИ для понимания.
Без воды, без истории, без биографий.

## Применение / Практическое использование
- Область применения 1
- Область применения 2
- Алгоритмы / протоколы / методы (если есть)

## Связи (Graph Hints)
- ТРЕБУЕТСЯ: [[статья_которую_надо_прочитать_до]]
- РОДИТЕЛЬ: [[более_общая_тема]]
- СМЕЖНЫЕ: [[статья1]], [[статья2]]
- ПРОТИВОРЕЧИТ: [[если_есть_противоречия]]

## Противоречия/Нюансы (Caveats)
- О чём часто ошибаются люди или ИИ?
- Распространённые заблуждения.
- Если нет — пропусти секцию.
```

## ВАЖНЫЕ ПРАВИЛА

1. **Запрещено:** история открытия, биографии учёных, примечания редакторов, ссылки на источники вида `[1]`.
2. **Обязательно:** формулы, числа, конкретные названия алгоритмов/протоколов.
3. **Язык:** тот же, что у входного текста (если статья на русском — ответ на русском).
4. **Фронтматтер:** заполни все поля осмысленно. `skill` — 2-5 релевантных тегов. `level` — оцен сложность. `prerequisites` — 1-3 статьи, которые нужно знать до этой.
5. **Связи:** укажи 3-7 реальных статей, с которыми связана эта тема. Формат `[[Article Name]]` — точное название статьи в Wikipedia.
6. **TL;DR и Embedding Target** — самые важные секции для векторного поиска. Делай их максимально информативными.
