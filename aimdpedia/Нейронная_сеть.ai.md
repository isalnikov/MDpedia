## TL;DR (Core Vector)
Нейронная сеть — вычислительная модель, вдохновлённая биологическим мозгом, состоящая из слоёв взаимосвязанных узлов (нейронов), обучающихся представлению данных через взвешенные связи и функции активации.

## Определение (Definition)
Искусственная нейронная сеть (ANN) — математическая модель, состоящая из слоёв искусственных нейронов, каждый из которых вычисляет взвешенную сумму входов с применением нелинейной функции активации. Обучается через обратное распространение ошибки.

## Ключевые факты (Facts)
- Перцептрон (Rosenblatt, 1958) — первый искусственный нейрон
- XOR-проблема (Minsky, 1969) — один перцептрон не решает нелинейные задачи
- Обратное распространение (backpropagation, 1986, Rumelhart-Hinton-Williams)
- Universal Approximation Theorem: сеть с одним скрытым слоем аппроксимирует любую непрерывную функцию
- Функции активации: sigmoid, tanh, ReLU (rectified linear unit), GELU, softmax
- Оптимизаторы: SGD, Adam, RMSprop, AdamW
- Регуляризация: dropout, L2, batch normalization, early stopping
- Глубокие сети: ResNet (152 слоя), GPT-3 (175B параметров), GPT-4 (оценка ~1.76T)

## Ядро для ИИ (Embedding Target)
Архитектура: Input Layer → Hidden Layers → Output Layer. Каждый нейрон: y = f(Σ wᵢxᵢ + b), где f — функция активации, w — веса, b — смещение.

Обучение:
1. Forward pass: вход → выходы сети
2. Loss function: MSE, cross-entropy — ошибка предсказания
3. Backward pass: градиенты ∂L/∂w через chain rule (backpropagation)
4. Gradient descent: w ← w - η × ∂L/∂w (η — learning rate)

Архитектуры:
- Feedforward (FNN): однонаправленные связи
- CNN (свёрточные): conv + pooling → компьютерное зрение
- RNN (рекуррентные): память предыдущих шагов → последовательности
- LSTM/GRU: решение vanishing gradient в RNN
- Transformer: self-attention → параллелизм, SOTA для NLP
- Autoencoder: сжатие и восстановление → reduction dim, генерация

Vanishing/exploding gradients: в глубоких сетях градиенты затухают или взрываются. Решения: ReLU, residual connections (ResNet), gradient clipping, proper initialization (He, Xavier).

## Применение / Практическое использование
- Компьютерное зрение: CNN (ResNet, EfficientNet) — классификация, детекция, сегментация
- NLP: Transformer (BERT, GPT, T5) — перевод, генерация, суммаризация
- Рекомендательные системы: Neural Collaborative Filtering
- Генерация контента: GAN (StyleGAN), диффузионные модели (DALL-E, Stable Diffusion)
- Автономные автомобили: мультимодальные сети (камеры + лидар + радар)
- Биология: AlphaFold (предсказание структуры белков)

## Противоречия/Нюансы (Caveats)
- Нейросети — универсальные аппроксиматоры, но не гарантируют корректность out-of-distribution
- Интерпретируемость: «чёрный ящик» — внимание (attention) ≠ объяснение
- Adversarial attacks: незаметные возмущения входа ломают предсказания
- Масштаб ≠ разум: большие модели — больше фактов, но не лучше рассуждений
- Вычислительная стоимость: обучение GPT-4 — >$100M, углеродный след
