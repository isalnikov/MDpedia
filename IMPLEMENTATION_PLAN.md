## Концепция

**MDpedia** — это knowledge base, оптимизированная для ИИ-агентов, а не только для человеческого чтения.

Формула:
```
AI-Wiki = Markdown-файлы + Граф связей + Семантические скиллы-теги
```

Три ключевые сущности:
1. **`.md` файлы** — чистые, минималистичные факты без воды и HTML-шума
2. **Граф файлов** — структура зависимостей, которая учит ИИ навигации
3. **Скилы** — исполняемые инструкции, дающие ИИ агентность

---

## Проблематика

### Почему обычная Википедия неудобна для ИИ?

| Проблема | Описание |
|----------|----------|
| **Шум** | 90% статьи — сноски, примечания, CSS/HTML обёртки, жрущие контекстное окно |
| **Длинные простыни** | LLM «тупеет» в середине длинного текста (lost in the middle) |
| **Отсутствие явных связей** | Нет взвешенного графа зависимостей («читай ТОЛЬКО после этих трёх») |
| **Нет исполнительных инструкций** | ИИ знает факты, но не знает *как именно* действовать |

### Пример `.md` файла для ИИ

```markdown
---
title: "Квантовая запутанность"
skill: [quantum-physics, cryptography]
level: advanced
prerequisites: [quantum-superposition, linear-algebra-basics]
embeddings:
  chunk_strategy: semantic-paragraphs
  max_tokens: 512
---

# Тема: Квантовая запутанность

## Определение
Явление, при котором квантовые состояния двух частиц оказываются
взаимозависимыми независимо от расстояния.

## Ядро для ИИ (Embedding Target)
Запутанность не передаёт информацию быстрее света. Измерение одной
частицы мгновенно определяет состояние другой. Применяется в E91 и
квантовых вычислениях.

## Связи (Граф)
- ТРЕБУЕТСЯ: `[[quantum_superposition]]`
- РОДИТЕЛЬ: `[[quantum_mechanics]]`
- ПРОТИВОРЕЧИТ: `[[local_realism]]`

## Скиллы (Вызов)
- `execute_simulation.skill.md` — симуляция схемы Белла
```

## Спецификация форматов

### Фронтматтер (YAML)

```yaml
---
title: "Заголовок статьи"
skill: [тег1, тег2, тег3]
level: beginner | intermediate | advanced
prerequisites: [файл1, файл2]
embeddings:
  chunk_strategy: semantic-paragraphs | headings | fixed-size
  max_tokens: 512
relations:
  requires: [файл1, файл2]
  parent: файл
  contradicts: [файл3]
---
```

### Семантические ссылки

Формат: `[[file#section|текст]](type:example)`

Типы связей:
- `type:example` — пример использования
- `type:prerequisite` — обязательное предварительное знание
- `type:contradiction` — противоречащая информация
- `type:extension` — углублённое изучение

### Скилл-файл (`.skill.md`)

```markdown
---
name: Python Memory Debug
version: 1.0
inputs: [python_code]
outputs: [memory_report, fix_suggestions]
---

# SKILL: Python Memory Debug

1. Запусти код с `tracemalloc`.
2. Сравни снэпшоты (код на Python).
3. Если циклические ссылки → вызови `gc.collect()`.
```

## Технический стек

| Компонент | Технология | Обоснование |
|-----------|-----------|-------------|
| **Скрипты** | TypeScript (Node.js) | Типизация, экосистема, AI-интеграции |
| **Markdown парсер** | unified/remark | Гибкость, плагины, AST |
| **Граф** | JSON + Graphology | Лёгкость, визуализация |
| **Векторная БД** | Chroma (локально) / Weaviate (облако) | RAG-интеграция |
| **Валидация** | Zod + AJV | Схема + рантайм проверка |
| **CI/CD** | GitHub Actions | Бесплатно, просто |
| **MCP Server** | Python (FastAPI) / Node.js | Интеграция с агентами |
| **Docs** | Astro + Starlight | Быстро, красиво |

## AI-first фичи

1. **Структурированный фронтматтер** — метаданные для фильтрации и ранжирования
2. **Семантические ссылки** — тип связи понятен ИИ (`type:prerequisite`, `type:contradiction`)
3. **Chunk-friendly разметка** — явные `##`, блоки кода с языком, списки
4. **Self-describing граф** — каждый файл знает входящие/исходящие связи
5. **Embedding Target секция** — оптимизированное ядро статьи для векторного поиска
6. **Контекстные правила** — порядок подачи тем (`context_rules/*.graph`)
