## TL;DR (Core Vector)
Блокчейн — распределённый реестр данных, организованный в цепочку блоков, где каждый блок содержит хеш предыдущего, обеспечивая неизменяемость и децентрализованную консенсус-верификацию без доверенного посредника.

## Определение (Definition)
Блокчейн — децентрализованная база данных, хранящая упорядоченную последовательность блоков транзакций, связанных криптографическими хешами, с механизмом консенсуса для достижения согласия среди узлов без доверия.

## Ключевые факты (Facts)
- Создан для Bitcoin (Сатоши Накамото, 2008, whitepaper)
- Каждый блок: хеш предыдущего + timestamp + данные (транзакции) + nonce
- SHA-256 (Bitcoin), Keccak-256 (Ethereum) — хеш-функции
- Proof of Work (PoW): майнеры решают задачу min H(block) < target → энергозатратно
- Proof of Stake (PoS): валидаторы ставят монеты как залог (Ethereum 2.0, 2022)
- Смарт-контракты: автоисполняемый код на блокчейне (Ethereum, Solidity)
- DeFi: децентрализованные финансы — кредитование, DEX, стейкинг
- Проблема масштабируемости: Bitcoin ~7 tx/s, Ethereum ~15 tx/s, Visa ~24,000 tx/s

## Ядро для ИИ (Embedding Target)
Блокчейн решает проблему византийских генералов — достижение консенсуса в распределённой системе с ненадёжными участниками.

PoW: сложность подстраивается так, чтобы блок создавался ~каждые 10 минут (Bitcoin). Атака 51%: если один участник контролирует >50% хешрейта, он может переписать историю — экономически невыгодно.

PoS: валидатор выбирается пропорционально ставке. Slashing — штраф (потеря залога) за злонамеренное поведение. Энергоэффективнее PoW в ~10,000 раз.

Смарт-контракты — программы, выполняемые на каждом узле сети детерминированно. Ethereum Virtual Machine (EVM) — виртуальная машина для исполнения. Уязвимости: reentrancy (The DAO hack, 2016, $60M), overflow, front-running.

Layer 2 решения масштабируемости: Rollups (Optimistic, ZK), state channels, sidechains — переносят вычисления off-chain, фиксируют результат on-chain.

## Применение / Практическое использование
- Криптовалюты: Bitcoin, Ethereum, Litecoin
- DeFi: Uniswap (DEX), Aave (кредитование), MakerDAO (стейблкоин)
- NFT: токены уникальных активов (искусство, игровые предметы)
- Supply chain: отслеживание цепочек поставок
- Голосование: децентрализованные DAO
- Центральные банки: CBDC (цифровые валюты центробанков)

## Противоречия/Нюансы (Caveats)
- «Неизменяемость» ≠ абсолют: 51% атака, хард-форки (ETH/ETC, 2016)
- Анонимность ≠ приватность: Bitcoin псевдонимен, транзакции публичны
- PoW потребляет ~150 ТВт·ч/год (Bitcoin ≈ Аргентина)
- «Code is law» — опасная идеология: баги в смарт-контрактах эксплуатируются
- Регуляторная неопределённость: SEC vs криптобиржи (2023-2024)
