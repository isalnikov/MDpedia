## TL;DR (Core Vector)
Машинное обучение (МО) — подраздел ИИ, изучающий алгоритмы, которые улучшают свою производительность на основе данных, без явного программирования правил. Включает обучение с учителем, без учителя и с подкреплением.

## Определение (Definition)
Машинное обучение — класс алгоритмов, способных обучаться на эмпирических данных: обобщать паттерны, делать предсказания и принимать решения, оптимизируя целевую функцию без детерминированного программирования.

## Ключевые факты (Facts)
- Формализация: Tom Mitchell (1997) — «программа обучается, если её производительность на задаче T улучшается с опытом E»
- Overfitting — модель запоминает данные, но не обобщает; решается регуляризацией, кросс-валидацией
- Bias-Variance Tradeoff — компромисс между недообучением и переобучением
- Gradient Descent — основной метод оптимизации весов модели
- Feature engineering — критический этап: качество признаков важнее алгоритма
- Train/Validation/Test split: типично 70/15/15 или 80/10/10

## Ядро для ИИ (Embedding Target)
Обучение с учителем (supervised): модель получает пары (вход, правильный_ответ) и настраивает веса для минимизации ошибки. Алгоритмы: линейная регрессия, SVM, random forest, градиентный бустинг (XGBoost, LightGBM), нейронные сети.

Обучение без учителя (unsupervised): модель ищет структуру в данных без меток. Алгоритмы: k-means, PCA, autoencoders, t-SNE.

Обучение с подкреплением (RL): агент взаимодействует со средой, получает reward/penalty. Алгоритмы: Q-learning, PPO, AlphaGo.

Deep learning — подкласс МО с многослойными нейронными сетями. Автоматически извлекает иерархические признаки, не требуя ручного feature engineering.

## Применение / Практическое использование
- Классификация: спам-фильтры, медицинская диагностика, fraud detection
- Регрессия: прогнозирование цен, спроса, погоды
- Кластеризация: сегментация клиентов, группировка документов
- Рекомендательные системы: collaborative filtering, content-based
- Компьютерное зрение: CNN (свёрточные сети)
- NLP: RNN, трансформеры, BERT, GPT

## Противоречия/Нюансы (Caveats)
- Корреляция ≠ каузальность: модель находит паттерны, но не причинно-следственные связи
- Data leakage — утечка информации из test set в train → завышенные метрики
- Нет free lunch theorem: не существует универсального лучшего алгоритма
- Интерпретируемость vs точность: линейные модели понятнее, нейросети точнее
